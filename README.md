# DWARS EMS Home Assistant

Home Assistant add-on repository voor DWARS EMS componenten.

## Inhoud

- `dwars_installer` — installeert de GoodWe custom component en kan de GoodWe Agent add-on installeren/configureren.
- `goodwe_agent` — GoodWe EMS bridge die Home Assistant GoodWe entities aanstuurt.
- `custom_components/goodwe` — aangepaste GoodWe custom integration met auto-discovery, MAC-opslag en IP-herstel.

## Installatie in Home Assistant

Voeg deze GitHub repository toe via:

Settings → Add-ons → Add-on Store → Repositories

Installeer daarna eerst `DWARS Installer` en start die één keer.
